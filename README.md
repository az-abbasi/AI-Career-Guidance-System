# AI Career Guidance System

An AI-based Career Guidance System developed as a Final Year Project to help students identify suitable career paths based on their academic background, skills, interests, and assessments.

## 📌 About the Project

The AI Career Guidance System provides personalized career recommendations to students. The system analyzes the student's academic records, skills, interests, and assessment results to suggest suitable career options and provide guidance for their future career development.

## ✨ Features

- Student Registration and Login
- Profile Management
- Academic Record Management
- Skill Assessment
- Interest Assessment
- AI-Based Career Recommendations
- Career Roadmap
- Goal Setting
- Progress Tracking
- PDF Career Report
